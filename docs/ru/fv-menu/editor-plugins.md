# Плагины редактора

Собственные аддоны FancyMenu патчат его редактор миксинами в пяти местах, потому что у редактора нет
точки расширения. Отсюда проблема «шаг в шаг»: любое изменение редактора может сломать любой аддон, а
аддон не на что писать, что было бы стабильно. Эта глава — пять хуков, которых хотели те миксины,
в виде одного модуля.

## Модуль

Один файл, `editor.plugin.js`, обычный ES-модуль с одним экспортом по умолчанию:

```txt
export default {
  types:     [{ id: 'ns:name', label, icon, schema, component, from, settings, defaults }],
  inspector: [{ match, section }],
  palette:   [{ group, items }],
  menu:      [{ menu, entry, run }],
  catalogue: { topics: [], actions: [] },
}
```

Все ключи необязательны. Ключ, которого редактор не знает, намеренно проваливает весь модуль, чтобы плагин,
написанный для более позднего редактора, не загрузился наполовину. `templates/editor-plugin/` — рабочий пример.

## Откуда он загружается

Два корня, оба читает доверенное действие `editor.plugins`:

| корень | для кого |
|---|---|
| `<gamedir>/fvui/editor-plugins/*.js` | плагин, который принадлежит установке игры, а не паку |
| `<pack>/editor/editor.plugin.js` | плагин, который несёт пак |

Плагин пака загружается, когда пак доверенный (лежит в jar) или когда его id указан в
`<gamedir>/fvui/editor-plugins/enabled.txt`, по одному id на строку. Больше ничего не загружается: пак, который игрок
положил в `fvui/packs/`, не получает права выполнять код в редакторе только потому, что его туда распаковали.

Плагин никогда не добирается до `editor.pack.*`. Он правит документ через хуки, а не через файловую систему,
а о плагине, бросившем исключение, редактор сообщает и пропускает его, вместо того чтобы упасть самому.

## Пять хуков

### types

Регистрирует тип элемента. Id имеет вид `<ns>:<name>`; имя без пространства имён — наше, и оно отклоняется.

```txt
types: [{
  id: 'example:badge',
  label: 'Badge',
  schema: { about: '...', component: 'Badge', fields: { label: { kind: 'text', about: '...' } } },
  from: '@example/fvui-elements',
  settings: { resizableY: false },
}]
```

`schema` — это `TypeSpec`, та же таблица, которой пользуются встроенные типы, так что валидатор, JSON-схема
и сгенерированный инспектор получают новый тип бесплатно — второго описания, которое нужно
синхронизировать, нет. `settings` — набор из 24 флагов возможностей из главы [Редактор раскладки](/ru/fv-menu/editor), так что редактор скрывает то, чего тип
не умеет, а не предлагает это, чтобы потом отказать.

`from` — пакет, который импортирует сгенерированный пак. При первом использовании редактор записывает соответствующую
запись `ExternalType` в блок `types` документа, так что **пак зависит от пакета с компонентом,
а не от плагина**: раскладка, сделанная с вашим плагином, генерируется и на машине, которая
его никогда не видела. Тип без `from` работает в редакторе, а генерирует неопределённый компонент — это
баг плагина, а не редактора.

`component` — компонент Svelte, который монтирует холст редактора; регистрируется через
`registry.register('ns:name', C)`. Задавайте оба: `component` для холста, `from` для пака.

### inspector

Добавляет один раздел в панель существующего типа — именно ради этого аддоны оригинала сегодня
ставят миксины. `match` — тип элемента или `*` для всех типов.

```txt
inspector: [{ match: 'button', section: { title: 'Example', fields: { rank: { kind: 'enum', values: [...] } } } }]
```

### palette

Записи в списке New Element, сгруппированные под вашим собственным заголовком.

### menu

Одна запись в строке меню редактора. `menu` — это `layout`, `edit`, `element`, `window` или `help`.

### catalogue

Темы и действия, которые регистрирует ваш мод, объявленные до того, как кто-либо подписался. `api.catalogue`
сообщает, что зарегистрировала игра, а у темы без подписчиков нет опрошенного значения, так что
выбор привязок не узнал бы о существовании вашей темы, пока что-нибудь её не прочитало. Объявление здесь также
пополняет `KNOWN_TOPICS` — благодаря этому `topic.example.rank` разбирается в `visibleIf` без
обходного `topic['example.rank']`.

## Чем это не является

- Не миксин. Заменить панель редактора нельзя, можно только добавить в неё.
- Не файловый API. `editor.pack.*` для плагина отклоняется.
- Пока без версий. Есть один набор хуков и один редактор; согласование версий появится, когда
  набор впервые изменится несовместимо, а до тех пор неизвестный ключ — ошибка.
- Не зависимость пака во время работы. См. `from` выше: сгенерированный пак импортирует ваш пакет
  с компонентом напрямую.
