# Что такое FateVis

FateVis запускает браузерный движок [Servo](https://servo.org) внутри Minecraft. Меню, экран
загрузки и HUD становятся обычной веб-страницей.

Чтобы поменять интерфейс, Java не нужна: HTML, CSS и JS, с Vue, Svelte, React или вообще без
фреймворка. Игра отдаёт странице данные и принимает от неё действия через один объект —
`window.fvui`.

## Три мода

| мод | jar | что это |
|---|---|---|
| [FV-UI](/ru/fv-ui/) | `fv-ui` | движок и API: Servo, мост, паки, права, SDK |
| [FV-Menu](/ru/fv-menu/) | `fv-menu` | альтернатива FancyMenu: титульный экран, скины экранов, страница загрузки, редактор |
| [FV-Hud](/ru/fv-hud/) | `fv-hud` | HUD в мире, чат, тосты, таб-лист и экраны контейнеров |

FV-Menu и FV-Hud построены на FV-UI и не зависят друг от друга: можно поставить любой из них
отдельно. Четвёртый, необязательный jar — `fv-earlywindow` — показывает страницу загрузки с первой
секунды запуска.

## Как это устроено

```txt
index.html            страница пака: титул, загрузка, скин экрана или HUD
    |  window.fvui    call, on, state
fvui (мод NeoForge)   данные игры как темы, действия игры, проверка прав на каждый вызов
    |  JNI
fvui-servo (Rust)     встроенный Servo 0.5, протокол fvui://, готовый кадр рисуется в игре
```

На этом можно построить две вещи:

- **UI-пак**: HTML, CSS и JS, которые заменяют титульный экран, страницу загрузки, скины экранов
  или HUD. Без Java и без обязательной сборки. Начните с [быстрого старта](/ru/fv-ui/quick-start).
- **мод-аддон**: Java-код, который регистрирует данные и действия игры, доступные любому паку.
  Начните с главы [Addon mods](/en/fv-ui/addons-java) (EN).

И то и другое работает через один объект моста и одну модель прав.

## Правила дома

- Страница — недоверенная, Java — доверенная. Всё, что выходит к игроку или в мир за пределы
  страницы, — это [право](/en/fv-ui/capabilities), о котором игра спрашивает на экране, который
  рисует сама.
- Один активный пак на вид. Меню — это один документ, который переключает режимы, а не страница
  на каждый экран.
- Servo 0.5 — не Chromium. Прочитайте [матрицу поддержки](/en/fv-ui/servo) до выбора фреймворка
  или библиотеки компонентов.
- Данные игры читаются как темы, а не выскребаются: тема считается, только пока на неё кто-то
  подписан.
- Пак, присланный сервером, никогда не считается доверенным: фиксированный белый список, одно
  согласие на сервер и никакого доступа к файлам или командам от вашего имени.

## Версии

| что | значение |
|---|---|
| FateVis | 0.1.0 |
| Minecraft | 1.21.1 |
| NeoForge | 21.1.250 (диапазон `[21.1,)`) |
| Java | 21 |
| Servo | 0.5.0 |
| API моста | тот же 0.1.0, пак объявляет диапазон в поле `fvui` манифеста |

Один номер версии на мод, диапазон в манифесте и зависимость аддона. Пак, работающий на 0.1.0,
объявляет `"fvui": ">=0.1.0"`.
