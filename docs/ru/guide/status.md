# Статус и история версий

**0.1.0, 15.09.2026.** Первая сборка. Servo работает внутри Minecraft 1.21.1 на NeoForge 21.1.x, и
веб-страница — это меню, экран загрузки и HUD. Четыре jar-файла, в одном из них нативные
библиотеки для Linux x64 и Windows x64.

Один номер версии на мод, API моста и диапазон `fvui` в манифесте. Пока версия 0.x, ломающее
изменение моста или формата пака поднимает минорную версию — и запись об этом прямо говорит,
потому что именно по диапазону `fvui` пак отказывается загружаться.

## Известные ограничения

- FV-Hud ещё ни разу не запускался в игре на Windows; сама сборка под Windows есть, но в игре не
  подтверждена.
- macOS не собирается.
- Пакеты `@fvui/*` не опубликованы в npm. Тарболы лежат в `dist/sdk/`, а пак вне дерева исходников
  подключает их как `file:`-зависимость.
- Идентификатор мода ещё может поменяться до первого публичного релиза: в NeoForge нет механизма
  алиасов. Имя `fvui` в протоколе `fvui://`, в `window.fvui` и в пространстве имён звуков останется.

## Не выпущено

### Добавлено

- `coexist` в `config/fvmenu-compat.json` (`ours`, `theirs`, `off`, переопределяется через
  `-Dfvmenu.coexist`): кто владеет титульным экраном, когда установлен FancyMenu.

### Исправлено

- FancyMenu перехватывал все клики на нашей титульной странице. Теперь наши экраны попадают в
  собственный чёрный список экранов FancyMenu — рефлексией, без зависимости при компиляции.
- Экран со скином, закрытый действием страницы во время собственной отрисовки, больше не роняет
  клиент.

|---|---|---|
| M1 | Слой данных | типизированный API данных и действий игры, мост с проверкой origin, счётчики по кадрам |
| M2 | UI-паки | манифест, поиск и проверка паков, уровни прав с экраном согласия, хранилище `fvui_data/`, `fvui://res/`, токены тем и пресеты, звуковой мост, перезагрузка по F6, отключение упавшего пака |
| M3 | Набор разработчика | `@fvui/sdk` с адаптерами vue, svelte и react, четыре шаблона паков и `templates/addon-java`, эта документация |
| M4 | Воссоздание A | Vue-пак, повторяющий изученный титульный экран FancyMenu со сгенерированной графикой-заглушкой |
| M5 | База FV-Hud | отдельный мод и отдельный вид, десять тем HUD, набор отменяемых ванильных слоёв, предметы игры внутри прямоугольников страницы |
| M6 | Редактор слоёв HUD | `hud.json` v2 с якорями и clip-прямоугольниками, восемь действий `hud.*`, прозрачный оверлей-редактор в игре |
| M7 | Загрузка | один поток `loading.*` на пять фаз, страница загрузки и `fv-earlywindow`, рисующий с первой секунды запуска |
| M8 | Редактор v1 | `layout.json` формата 1, `@fvui/layout`, `@fvui/elements`, `@fvui/codegen` с CLI, редактор на Svelte, таймлайны, панель кода в игре с линтером ограничений Servo |
| M9 | Контейнеры | оформление всех экранов контейнеров, перекладка инвентаря и сундуков, вкладки креатива, поиск и скроллбар, хост иконок `fvui://item/` |
| M10 | Чат и оверлеи | `ComponentHtml` с таблицей кликов, которую страница не может прочитать, шрифт Minecraft, запечённый в TTF, чат, подсказки, тосты, таб-лист и экран смерти |
| M11 | Распространение | выделенный сервер, канал `fvui:data` с лимитами и политикой сервера, `/fvui` и `/fvuic`, паки от сервера с согласием, укрепление загрузки на Windows, экспорт и импорт наборов |
| M12 | Паритет | 30 действий, 15 тем паритета, 188 сопоставленных плейсхолдеров, `FvUiApi.events()` с 27 каналами, API плагинов редактора из пяти хуков без миксинов, медиасборка отдельным jar |
| M14 | Реактивный HUD | темы `hud.damage`, `hud.status` и `hud.reactive`, привязка боссбаров к сущностям, блок `reactive` в `hud.json` |
