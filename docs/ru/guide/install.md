# Установка

Четыре jar-файла в `<gamedir>/mods/`. Обязателен только первый, остальные — по желанию.

| jar | что это | нужен |
|---|---|---|
| `fv-ui-0.1.0.jar` | движок, внутри нативные библиотеки для Linux x64 и Windows x64 | - |
| `fv-menu-0.1.0.jar` | титульный экран, скины экранов, страница загрузки | fv-ui |
| `fv-hud-0.1.0.jar` | HUD в мире, чат, контейнеры | fv-ui, от fv-menu не зависит |
| `fv-earlywindow-0.1.0.jar` | необязательно: экран загрузки с первой секунды запуска | - |

## Требования

| | |
|---|---|
| Minecraft | 1.21.1 |
| NeoForge | 21.1.250 и новее в ветке 21.1 |
| Java | 21 |
| Linux x64 | основная платформа разработки |
| Windows x64 | собрано, в игре пока не подтверждено |
| macOS | пока не собирается |

## Где что лежит

```txt
<gamedir>/mods/               jar-файлы
<gamedir>/fvui/packs/<id>/    пак-папка
<gamedir>/fvui/packs/<id>.zip пак-архив
<gamedir>/fvui/packs.json     какой пак активен на каком виде и выданные права
<gamedir>/fvui_data/<id>/     собственные данные пака
```

Ни `fvui/`, ни `fvui_data/` не лежат в `config/`, поэтому обновление модпака, которое
перезаписывает `config/`, не трогает паки и их данные. Подробности — в главе
[Distribution](/en/fv-ui/distribution) (EN).

## Как поставить пак

Положите папку или zip пака в `<gamedir>/fvui/packs/`, затем на титульном экране нажмите
<kbd>K</kbd> — откроется выбор пака. Пока игра запущена, <kbd>F6</kbd> перечитывает все манифесты
и перезагружает текущий экран без перезапуска.

Когда пак впервые просит что-то за пределами страницы (выйти из игры, зайти на сервер, открыть
ссылку), игра показывает собственный экран согласия. См. [Capabilities](/en/fv-ui/capabilities) (EN).

## Вместе с FancyMenu

`coexist` в `config/fvmenu-compat.json` решает, кто владеет титульным экраном, когда установлен
FancyMenu: `ours`, `theirs` или `off`.

## Сборка из исходников

Linux x86_64:

```sh
cd native && cargo build --release
cd web && npm install && npm run build && npm run build:menu
cd mods && ./gradlew :menu:runClient
```

Если что-то не запускается, в главе [Troubleshooting](/en/fv-ui/troubleshooting) (EN) перечислены
строки лога, которые стоит искать.
