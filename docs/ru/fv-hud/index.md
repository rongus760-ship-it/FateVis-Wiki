# FV-Hud

`fv-hud-0.1.0.jar` — второй мод на том же движке: сердца, хотбар, эффекты, боссбары, чат и экраны
контейнеров рисует страница. Нужен [FV-UI](/ru/fv-ui/); от FV-Menu он не зависит, и наоборот —
любой из них можно поставить отдельно.

## Чем страница HUD отличается от остальных

- **Она не получает ввод.** Вид HUD создаётся вне любого экрана и остаётся без фокуса, поэтому
  страница не может перехватить клик, кейбинд или колесо хотбара. Единственное узкое исключение —
  экран чата.
- **Один CSS-пиксель равен одному GUI-пикселю.** Вид масштабируется по GUI scale игрока, так что
  ванильные отступы пишутся в вёрстку как есть.
- **Ресурспаки действуют.** Спрайты приходят с `fvui://res/`, и страница рисует то, что загружено
  у игрока.
- **Предметы рисует игра.** Страница сообщает прямоугольники через `hud.rects`, а игра рисует в
  них настоящие стаки предметов.
- **Он существует только в мире.** Вид создаётся при входе в мир и закрывается при выходе.

## HUD-пак

Тот же манифест, что и у любого пака, с `hud` в `entries`:

```json
{
  "id": "my-hud", "version": "1.0.0", "name": "My HUD", "fvui": ">=0.1.0",
  "entries": { "hud": "index.html" },
  "capabilities": ["state.sub", "state.unsub", "hud.rects"],
  "res": ["minecraft/textures/gui/sprites/hud/hotbar.png"]
}
```

Выбирается через `active.hud` в `<gamedir>/fvui/packs.json`. Чего в паке нет, берётся из штатного
HUD, а пак с одним `theme` перекрашивает штатную страницу.

## Темы

Все они ленивые: страница без сердец ничего не платит за `hud.player`.

| тема | что в ней |
|---|---|
| `hud.player` | здоровье, поглощение, голод, броня, воздух, опыт, имя предмета в руке |
| `hud.hotbar` | девять слотов, выбранный слот, вторая рука |
| `hud.effects` | эффекты с их дедлайнами |
| `hud.title` | заголовок, подзаголовок и action bar |
| `hud.bossbars` | боссбары, привязанные к своим сущностям |
| `hud.scoreboard` | сайдбар |
| `hud.damage`, `hud.status`, `hud.reactive` | реактивный HUD, см. ниже |

Время передаётся абсолютными дедлайнами в gui-тиках, а не обратным отсчётом, поэтому между
обновлениями страница анимирует сама.

## Реактивный HUD

`hud.damage` несёт по одному сообщению на удар — с направлением и типом урона; `hud.status`
говорит, в какой беде игрок: `lowHealth`, `critical`, `starving`, `drowning`, `frozen`, `onFire`,
`poisoned`, `withered` и другие. Штатная страница превращает их в края экрана по типу урона,
трещины на сердцах, пульс при критическом здоровье и вспышки. Блок `reactive` в `fvui/hud.json`
включает каждый эффект отдельно и задаёт интенсивность.

## Не только сердца

| | |
|---|---|
| чат | HUD чата и экран чата, шрифт Minecraft запекается в TTF во время работы |
| оверлеи | тосты, таб-лист, подсказки, экран смерти |
| контейнеры | оформление всех экранов контейнеров, перекладка инвентаря и сундуков, вкладки креатива; для JEI, EMI и REI есть зоны исключения |
| редактор слоёв | прозрачный оверлей в игре: якоря и clip-прямоугольники для каждого слоя, сохраняется в `hud.json` |

Всё это — одна большая справочная глава: [The HUD surface](/en/fv-hud/hud-surface) (EN).
